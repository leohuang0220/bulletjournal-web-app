一天漫想筆記 PWA 安裝說明

【放到網路上】（擇一，都免費）
A. Netlify Drop：開 app.netlify.com/drop，把整個資料夾（不是 zip）拖進去，立刻得到網址。
B. Cloudflare Pages：建立專案 → Direct Upload → 上傳整個資料夾。
C. GitHub Pages：建一個 repo，上傳全部檔案，Settings → Pages → 選 main 分支。
網址必須是 https（以上三種都是）。

【裝到手機】
iPhone：用 Safari 開網址 → 分享 → 加入主畫面。
Android：用 Chrome 開網址 → 選單 → 安裝應用程式（或加到主畫面）。

【注意】
- 筆記存在該支手機的瀏覽器裡，不同手機不會同步。清除網站資料會一併清掉筆記。
- 第一次連網開啟後，之後離線也能用。
- 更新版本時，把 sw.js 裡的 mansiang-v1 改成 v2 再重新上傳，手機才會換成新版。
